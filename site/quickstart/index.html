    Quickstart

    This guide uses the implemented package API with a tiny in-memory collection. For a full SciFact workflow, see the home page.

    Install

    stratajanus requires Python 3.13 or newer. From the repository root:

    python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
python -m pip install -r requirements.txt

    The package itself uses the standard library. The pinned requirements include the tools needed for tests, SciFact scripts, and documentation.

    Build an index and search

    from stratajanus.index.inverted import build_index
from stratajanus.retrieval.bm25 import BM25

documents = [
    {
        "doc_id": "paper-1",
        "title": "Search systems",
        "text": "An inverted index supports retrieval.",
    },
    {
        "doc_id": "paper-2",
        "title": "Scientific evidence",
        "text": "Evidence supports a scientific claim.",
    },
]

index = build_index(documents)
ranker = BM25(index)

for result in ranker.search("inverted retrieval"):
    document = documents[result.internal_id]
    print(result.doc_id, result.score, document["title"])

    build_index assigns internal IDs in input order and stores the original IDs separately. The result score is an uncalibrated BM25 ranking score. Repeated query terms count once; ties preserve input order. See the indexing guide for the tokenizer and posting format, and the API reference for all public package and script APIs.

    Search SciFact

    After installing dependencies, fetch and prepare the dataset, then run the search script:

    python scripts/download_scifact.py
python scripts/prepare_scifact.py
python scripts/search_scifact.py "evidence for a scientific claim" --top-k 10

    The CLI builds the index in memory on each run. The data download and conversion steps write under ignored data/ directories. Dataset structure and preparation details are in SciFact data.

    Tests and documentation preview

    python -m pytest
mkdocs serve

    MkDocs Material and mkdocstrings are included in the pinned requirements.txt toolchain. To build a static documentation site, run mkdocs build --strict.
