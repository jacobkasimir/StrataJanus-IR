# Contributing

## Setup

Use Python 3.11 or newer, create a virtual environment, then run `make install`.

## Code style

Use type hints for public functions, document modules and APIs, and run `make lint` and `make typecheck` before submitting.

## Tests

Run `make test`. Keep unit tests deterministic and offline.

## Commit messages

Use Conventional Commits, such as `feat: add postings format` or `docs: clarify evaluation protocol`.
